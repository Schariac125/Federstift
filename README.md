# 羽笔 Federstift

> Federstift 不替你写故事，只替你把故事从头到尾记牢——设定、风格、伏笔，一个都不丢。

羽笔（Federstift）是一款面向长篇小说创作的 AI 写作工具。输入一句故事要求，总规划、创作、审查三个 Agent 会协同完成「全局规划 → 分段写作 → 多维审查」的完整流程；设定库、风格库与深度 RAG 检索共同保障长篇叙事的设定一致性；自动 / 逐段 / 逐章三种审批模式让你按自己的节奏掌控创作过程。

## 项目特性

### 三 Agent 协同创作

- **总规划 Agent**：理解创作意图，制定全局策略——先写什么、何时提问、何时审查、风格如何把控，不直接生成正文。
- **创作 Agent**：在规划约束与 RAG 检索结果下逐段生成正文，支持流式输出。
- **审查 Agent**：从情节、人物、设定一致、文风、逻辑、语言、节奏七个维度审查，输出严格 JSON 报告。

### 深度 RAG 设定一致性

- 轻量 BM25 检索融合设定库、风格库、已写章节、时间线、作者答复五类来源；章节索引增量缓存保证长篇（数十万字）写作不卡，正文每段只追加新增部分。
- 规划与审查时的**设定摘要按相关性取 TopK**（BM25），而不是简单截取知识库前几条，越写越准；
- **宏观一致性检查**不把整本书塞给 AI：按「章节目录 + 最近章节全文 + 开篇基础章节选」组合取上下文，超出预算时优先保住最新进展。

### 人机协同审批

- 三种模式：**自动**（生成即采纳）/ **逐段**（每段确认、修改、打回）/ **逐章**（章末统一确认），创作中可随时切换；
- **自动模式**由规则层即时裁决审查意见（0 次额外模型调用，不打断写作）：error 级问题、审查明确的定向修改、设定一致性 warning 或 warning≥2 触发自动重写，同一章最多自动重写 1 次防死循环，其余记录后继续；
- **逐段 / 逐章模式**下，审查报告完整呈现给你，由你决定**重写 / 忽略 / 调整下次审查力度**（GUI 与 CLI 口径一致）；
- 重写采用**定向重写**：创作 Agent 先按审查意见生成「重写方案」，只重写方案指定的段落，保留已确认的优点，不满意可一键打回再改；
- **反复返工诊断**：同一章重写 2 次以上仍未通过时，总规划 Agent 先诊断问题根源（正文 / 计划 / 理解偏差），再把诊断方向注入新的重写方案；
- **计划级修正**：宏观一致性检查发现跨章节结构性问题时（自动模式），总规划 Agent 自动修订后续创作计划，正文保持不动。

### 个人知识库

- **设定库**：对话式创建，或粘贴文字自动提取设定（硬性事实优先引用）；
- **风格库**：范例式创建——贴一段喜欢的文字，自动提炼写作规则；
- **提问模板库**：`{变量}` 占位复用常用提问。

### 反馈学习

- 你在创作中亲手修改的段落会被记录，之后可提炼为风格偏好，经你确认后写入风格库——AI 会越来越像你。

### 灵活配置

- 支持任意 OpenAI 兼容模型供应商（OpenAI / DeepSeek / 自定义）；
- 零配置可用：不填任何 Key 也能用离线演示模式体验完整流程；
- 总规划 / 创作 Agent 系统提示词可自定义（留空回落内置默认）；
- 审查重点方向与严格 / 标准 / 宽松三档力度，均可全局配置或按作品覆盖。

### 图形界面与命令行

- 双击 `run.bat` 启动图形界面（GUI），作品、知识库、设置全部可视化；
- 同时提供 CLI 入口，适合终端用户。

## 未来可能的优化方向

- **检索增强**：引入向量检索与 BM25 混合排序、离线嵌入缓存，进一步提升长篇相关性；
- **设定管理**：设定版本化、冲突检测、跨章节自动追踪；
- **导出能力**：一键导出 epub / docx / PDF，附目录与封面；
- **创作可视化**：章节目录拖拽重排、情节时间线视图、角色卡管理；
- **模型路由**：为规划 / 创作 / 审查分别自动选择最合适的模型；
- **知识导入**：支持从 PDF / Word 等文档导入设定与参考材料；
- **多设备协作**：自托管同步或多用户协作；
- **审查规则可插拔**：自定义审查维度与检查规则，扩展审查 Agent 的能力边界。

## 快速开始（非开发者）

1. 安装 [Node.js 18+](https://nodejs.org/)（安装包一路「下一步」即可）。
2. 双击 **`install.bat`**，完成依赖安装与构建（只需一次，需联网）。
3. 双击 **`run.bat`** 启动——会自动打开浏览器进入图形界面。
4. 在「开始创作」输入故事要求，点「🚀 开始创作」。

不配置任何模型也能使用：此时走**离线演示模式**，可完整体验「规划 → 写作 → 审查 → 修改」流程；正式创作请在「模型与设置」里填入你自己的 API Key。

> 遇到问题？命令行执行 `node dist/cli/index.js doctor` 做一次环境自检。
> 完整操作手册见 [docs/使用说明书.md](docs/使用说明书.md)。

## 图形界面（GUI）

双击 `run.bat`（或执行 `node dist/cli/index.js gui`）后，服务监听 `http://127.0.0.1:3377` 并自动打开浏览器。界面包含：

- **我的作品**：作品列表与进度，一键继续创作；卡片上可删除作品（删除前二次确认）；
- **开始创作**：输入要求，选择知识库、审批模式、审查重点与力度；
- **创作台**：全屏写作页面，规划 / 写作 / 审查过程实时流式显示，正文逐字浮现；
- **深浅色切换**：侧边栏与创作台右上角一键切换，偏好自动记忆（首次跟随系统）；
- **知识库**：设定库 / 风格库 / 提问模板库 / 反馈学习；
- **模型与设置**：模型供应商、审批模式默认值、宏观检查间隔、审查重点与力度、RAG 开关、Agent 自定义提示词；
- **使用说明**：内置帮助页。

## 命令行（可选）

图形界面覆盖了全部功能；高级用户仍可使用命令行：

```bash
node dist/cli/index.js gui       # 打开图形界面（推荐，run.bat 默认入口）
node dist/cli/index.js start     # 开始创作（交互引导）
node dist/cli/index.js demo      # 离线演示创作
node dist/cli/index.js resume    # 续写已有作品
node dist/cli/index.js kb        # 知识库管理（设定 / 风格 / 模板 / 反馈学习）
node dist/cli/index.js config    # 模型与设置
node dist/cli/index.js doctor    # 环境自检
node dist/cli/index.js version   # 查看版本
node dist/cli/index.js help      # 帮助
```

## 目录结构

```
federstift/
├─ run.bat / install.bat    # 双击即用的启动与安装脚本（Windows）
├─ gui/public/index.html    # 图形界面前端（单文件，无构建工具）
├─ src/
│  ├─ agents/               # 三 Agent：总规划 / 创作 / 审查
│  ├─ rag/                  # RAG：BM25 + 索引 + 上下文构建
│  ├─ gui/                  # GUI 后端：会话状态机 + 本地 HTTP 服务
│  ├─ pipeline/             # 创作流水线：章节推进 / 审批网关 / 审查调度 / 持久化
│  ├─ learning/             # 反馈学习：偏好提炼 / 合并去重 / 写入风格库
│  ├─ kb/                   # 知识库：设定 / 风格 / 模板 / 自动提取
│  ├─ core/                 # 配置 / LLM 客户端 / 存储
│  └─ cli/                  # 命令行入口
├─ scripts/                 # smoke / e2e / gui_e2e 测试
├─ docs/使用说明书.md        # 面向非开发者的使用手册
└─ workspace/               # 你的数据（作品 / 知识库 / 反馈 / 设置）
```

## 开发指南

环境要求：Node.js 18+。

```bash
npm install       # 安装依赖（仅开发依赖：TypeScript 与类型声明）
npm run build     # 编译到 dist/
npm run typecheck # 类型检查
npm run smoke     # 冒烟测试
npm run e2e       # 端到端验收
npm run gui_e2e   # GUI 端到端验收
npm run gui       # 启动图形界面
npm run doctor    # 环境自检
```

测试脚本使用独立临时工作区运行，不会触碰 `workspace/` 里的真实数据（通过 `FEDERSTIFT_WORKSPACE` 环境变量隔离）。

## 数据与隐私

- 数据保存在项目下的 `workspace/`：作品（`novels/<作品>/manuscript.md`）、知识库（`settings/ styles/ templates/`）、设置（`config.json`）、修改反馈（`feedback/`）。
- 创建作品时若填了作品名，`novels/` 下的文件夹以作品名命名（重名自动加序号）；未填则用内部编号。
- API Key 只保存在 `config.json`；仅当调用你配置的模型 API 时，当次创作上下文会发送给你自己的供应商。
- GUI 服务默认只监听 `127.0.0.1`，不暴露到局域网或公网。
- 删除知识库条目是「留痕」式软删除；删除作品会连同正文、创作计划、审查记录永久移除（GUI 删除前二次确认）。
