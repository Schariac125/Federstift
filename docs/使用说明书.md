# 羽笔 Federstift · 使用说明书

> 版本 0.10.0

## 一、这是什么

羽笔是一款 AI 长篇小说创作工具。你输入故事要求，它分章分段地帮你写；你可以建立自己的**设定库、风格库和提问模板库**，让 AI 记住你的人物、世界观与文风；「自动 / 逐段 / 逐章」三种**审批模式**让你决定对创作过程的掌控力度。

羽笔带**图形界面（GUI）**：双击启动后自动打开浏览器，作品列表、创作会话、知识库、设置全部可视化操作，不需要记任何命令。

## 二、安装与启动

1. 安装 [Node.js](https://nodejs.org/)（LTS 版本即可，安装时一路点「下一步」）；
2. 双击本目录下的 **`install.bat`**（一次性安装依赖并构建，需要联网）；
3. 双击 **`run.bat`** 启动——会自动打开浏览器进入图形界面；
4. 遇到问题时，命令行执行 `node dist/cli/index.js doctor` 可做环境自检（Node 版本 / 工作区 / 供应商 / 编译产物）。

> 提示：双击后窗口一闪而过，请右键 `run.bat` →「以管理员身份运行」或查看窗口中的错误提示。
> 浏览器没有自动打开？手动访问 `http://127.0.0.1:3377`（服务只监听本机，数据不会暴露到网络）。

## 三、创作功能

### 开始创作

点左侧「**开始创作**」，填写：

1. **作品名**（可留空，之后随时能补）；
2. **故事要求**（必填，一句话到几段话都可以）；
3. **计划写多少章**（用于全局规划，默认 10 章）与**这次先写几章**（默认 1 章）；
4. 可选：**审查重点**（如设定一致性、人物动机；留空 = 用全局默认）与**审查力度**（严格 / 标准 / 宽松）；
5. 可选：勾选要挂上的**风格库 / 设定库**（不选也能写，AI 会自动按相关性检索全部知识库）；
6. 点「🚀 开始创作」。

总规划 Agent 会先制定创作计划。计划里的问题（开局前 + 每章前）会在页面上逐个出现，**都可以留空跳过**，绝不强迫回答。之后创作 Agent 开始分段写作，正文在创作台里逐字流式浮现。

### 三种审批模式

- **自动**：生成即采纳，适合安静流淌；
- **逐段**：每段确认 / 修改 / 重写 / 打回，细致掌控；
- **逐章**：章末统一确认。

创作中可随时切换：会话页右上角「审批模式」下拉，选择后立即生效（当前作品与全局默认同步）。逐段待审时切到自动 / 逐章，当前段会被直接采纳，不打断节奏。

### 审查与重写

- 规划指定的章节审查与每 N 章宏观一致性检查自动触发；报告按你设定的**审查重点**与**审查力度**生成；
- **逐段 / 逐章模式**：审查报告（评分 + 问题清单 + 修改建议）会**完整呈现在你面前**，由你决定：**重写本章**（落实审查意见）/ **忽略继续** / **调整下次审查力度**；
- **自动模式**：系统按固定规则即时裁决，不打断写作——有 error 级问题、审查给出定向修改、设定一致性 warning 或 warning 达到 2 条时自动重写；其余情况记录后继续；同一章**最多自动重写 1 次**，仍未通过则保留当前版本，不会陷入死循环，你随时可手动重写；
- **重写方式**：创作 Agent 先根据审查意见生成**重写方案**，优先按方案逐段落实——只重写审查指出的段落，其余保留；方案没有指定段落时才整章重写；
- **反复返工诊断**：同一章重写达到 2 次仍未通过时，总规划 Agent 会先诊断「改不好的根源」（正文问题 / 计划问题 / 审查与创作理解偏差），再把诊断方向注入新的重写方案；
- **计划级修正**：宏观一致性检查发现跨章节结构性问题时（自动模式），总规划 Agent 会修订后续创作计划，正文保持不动；
- 宏观检查按「章节目录 + 最近几章全文 + 开篇基础章节选」组合取上下文，超出预算时优先保留最新进展——写到几十万字依然稳定；
- 右上角「审查力度」下拉可随时调整本作品的严格程度，**下一次审查立即生效**。

### 续写与删除

- 「我的作品」列表里可一键**继续创作**（停止后回来接着写）；
- 作品卡片上「删除」会**永久删除**该作品文件夹（正文 / 创作计划 / 审查记录一并移除），删除前二次确认，删除后无法恢复。

## 四、知识库功能

点左侧「**知识库**」。知识库全部可选，但建议用起来——这是长篇设定一致性的关键。

### 设定库（让 AI 记住你的世界）

两种创建方式：

1. **对话式创建**：填类别、名字、描述；点「预览硬性事实」可勾选要保留的硬性事实，再填别名与标签保存；
2. **自动提取**：把一段人物介绍 / 世界观描述粘贴进去，点「识别候选」，勾选确认后保存。

硬性事实是「不可违背」的设定，一致性检查会优先引用。

### 风格库（范例式创建）

把你喜欢的段落粘贴进「范例文本」（自己写的，或你有权使用的样例），点「提炼并保存」——工具会自动分析出人称视角、句子长短、对话占比、氛围倾向等规则；配置了模型且勾选「用 AI 精修」时，AI 会进一步提炼。保存后可点「编辑」增删规则。之后创作挂上这个风格，AI 就会按这些规则写。

### 提问模板库

保存常用的提问问法，正文里可以用 `{变量}` 占位，例如：

```
请为 {人物名} 写一段 200 字的小传，突出 {特征}。
```

### 反馈学习（AI 从你的修改中学风格）

创作时如果你选择「修改这段」，你的修改会以「AI 原文 + 你的版本」的形式记录到 `workspace/feedback/`。

在「知识库 → **反馈学习**」页签里：

1. 点「分析我的修改」，工具用规则分析（离线可用）对比原文与你的修改，提炼偏好（句子长短、人称、对话占比、精简度、标点与语气词等）；
2. 勾选「用 AI 辅助分析」且已配置模型时，学习 Agent（严格 JSON 输出）会补充更细致的洞察；
3. 候选偏好按置信度列出，**由你勾选**要采纳哪些；
4. 选择写进风格库：可新建一个「从反馈中学习」风格，也可追加到你已有的某个风格（自动去重）；
5. 点「应用并写入风格库」，处理过的记录会标记为已学习，之后不再重复提示。

学习完成后，下次创作挂上该风格，AI 就会按你亲手调教出来的偏好写作。

## 五、模型与设置

点左侧「**模型与设置**」，支持：

- **OpenAI**：填入 API Key，模型默认 `gpt-4o-mini`；
- **DeepSeek**：填入 API Key，模型默认 `deepseek-chat`；
- **自定义**：任意 OpenAI 兼容接口，填接口地址、Key、模型名；
- **离线演示模式**：什么都不用填，先体验完整流程。

Key 只保存在 `workspace/config.json`，不会上传到任何地方。

同一页面还可以设置**全局默认**：

- **审批模式**：自动（安静流淌）/ 逐段（每段确认）/ 逐章（章末确认）；
- **宏观一致性检查间隔**（每几章自动检查一次设定是否自洽）；
- **审查重点**（优先检查设定一致性、人物动机、文风节奏等；留空 = 全维度）；
- **审查力度**（严格 / 标准 / 宽松）；
- **RAG 检索**开关与每次注入的相关条数；
- **总规划 / 创作 Agent 系统提示词**：两个文本框中可改写 Agent 的「人设」与工作规则（例如把总规划师改成更严肃的编辑、让创作 Agent 按你的文风要求写作）。**留空 = 使用内置默认**；点「恢复默认」即清空。保存后，新建作品立即生效。

## 六、图形界面

- 深浅两套配色：侧边栏底部与创作台右上角的「🌙 / ☀️」可随时切换，选择会被记住；
- 深色写作台风格，左侧导航：**我的作品 / 开始创作 / 知识库 / 模型与设置 / 使用说明**；
- 创作台提供五个页签：**正文 / 创作计划 / 审查记录 / 作者答复 / 活动日志**；
- 审批、审查、问答都以**卡片**形式呈现，按钮即点即用；
- 长时间生成时顶部会显示进度提示，正文逐字流式浮现。

## 七、数据与文件

数据保存在项目根目录的 `workspace/` 文件夹，全部是普通文件，可以直接用记事本 / VS Code 打开：

```
workspace/
├─ config.json              # 模型、审批模式等设置
├─ styles/                 # 风格库（每条一个 JSON）
├─ settings/               # 设定库（每条一个 JSON）
├─ templates/              # 提问模板库
├─ novels/<作品>/          # 你的作品
│   ├─ session.json        #   创作会话状态
│   ├─ manuscript.md       #   稿子（Markdown，可任意编辑）
│   ├─ plan.md             #   创作计划
│   └─ reviews.md          #   审查记录
└─ feedback/               # 你修改过的段落（用于偏好学习）
```

想换电脑？把整个 `workspace` 文件夹拷走即可。

## 八、命令行（可选）

图形界面覆盖了全部功能；高级用户也可以在终端里用：

```
node dist/cli/index.js gui      # 打开图形界面（推荐，run.bat 默认入口）
node dist/cli/index.js help     # 帮助
node dist/cli/index.js config   # 直接进设置
node dist/cli/index.js kb       # 直接进知识库
node dist/cli/index.js demo     # 离线演示创作
node dist/cli/index.js start    # 开始创作
node dist/cli/index.js resume   # 续写作品
node dist/cli/index.js doctor   # 环境自检（Node 版本/工作区/供应商/编译产物）
node dist/cli/index.js version  # 查看版本
```

## 九、常见问题

**问：没有 API Key 能用吗？**
能。用离线演示模式体验完整流程；正式创作需要你自己的模型 API。

**问：我的稿子会丢吗？**
不会。每写完一段都会立即写入 `workspace/novels/<作品>/manuscript.md`，即使中途关掉窗口也不丢。

**问：关闭浏览器后创作会中断吗？**
创作进程由启动它的窗口托管。关掉浏览器标签页不中断；关掉启动窗口（或按 Ctrl+C）才会停止服务，已写内容全部已保存，下次打开可继续。

**问：删错了一条设定怎么办？**
删除只是给文件打上「已删除」标记，内容还在 `workspace/settings/` 里，可以手动改回。

**问：数据会传到网上吗？**
GUI 服务只监听 `127.0.0.1`（本机），不暴露到局域网或公网。只有调用你配置的模型 API 时，当次创作上下文会发送给你自己的供应商。

**问：写了几十万字会不会越来越慢？**
不会明显变慢。羽笔对已写章节做增量缓存：章节没变时检索直接复用，正文每段也只追加新增部分，不会每写一段就把整本书重新整理一遍。
